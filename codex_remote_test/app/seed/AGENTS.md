# Boundaries for the connection experiment

Respond in Swedish. Work only in /data/workspace with synthetic test material.
Do not access Home Assistant, Home Agent, the host, production household data,
credentials, other services or devices. Do not install plugins or configure
integrations. Never print tokens, auth files or environment variables.

Use normal Codex permissions and ask before work outside the test workspace.
The test is reading README.md, creating session-test.txt and resuming the same
conversation after an add-on restart. A successful test does not authorize any
Home Agent integration or deployment.
